# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct.

The full text is available at the link above and is incorporated here by reference.

## Reporting

Concerns about behaviour in project spaces (issues, pull requests, discussions) can be reported privately to the repository maintainer via **GitHub** — open a draft Security Advisory or send a direct message to the repository owner.

Reports will be reviewed and responded to within 7 days where possible. The reporter's identity will be kept confidential unless they consent to disclosure.

## Enforcement

Maintainers may take any action they deem appropriate, up to and including warning, temporary ban, or permanent ban from project spaces, in response to behaviour they consider inappropriate, threatening, offensive, or harmful.

Enforcement decisions follow the Contributor Covenant Enforcement Guidelines linked above.
